# 侧边栏页面与功能梳理

> 适用版本：XLT Workbench v0.1.3
> 说明：本文梳理左侧导航栏（`src/layouts/AppLayout.vue`）中每个页面/入口的用途、主要功能、数据来源与关键约束。
> 应用为「本地优先」桌面应用，依赖本机 CLI、文件系统与原生能力，**仅能在 Tauri 桌面壳中运行**（浏览器打开会提示「请在桌面应用中打开」）。

---

## 1. 侧边栏结构总览

侧边栏只放**一级入口**，按 4 个分组组织（共 11 项），底部 footer 固定为「设置 · 主题(图标) · 关于」：

| 分组 | 菜单项 | 路由 | 一句话用途 |
|---|---|---|---|
| 用量 | 概览 | `/dashboard` | 驾驶舱：订阅支出、Token、额度峰值与油价/日报卡片 |
| 用量 | 分析 | `/analytics` | Token 明细统计、热力图与多维度图表 |
| 用量 | 订阅与账单 | `/subscriptions` | 套餐额度 + 订阅管理 + 账单流水 |
| Skills | 概览 | `/skills` | Skills 总览与近期动态 |
| Skills | 技能库 | `/skills/library` | 浏览/搜索/新建/编辑已安装 Skills（带**错误数**徽章） |
| Skills | 安装 | `/skills/install` | 从远程/本地/压缩包安装 Skill |
| MCP | MCP 服务 | `/mcp` | MCP 服务列表 + 启停 + 编辑（**预留**，当前为只读占位） |
| 工具 | 剪贴板历史 | `/clipboard` | 浏览本机剪贴板历史 |
| 工具 | 代码片段 | `/snippets` | 保存与复用代码/命令/Prompt 片段 |
| 工具 | 密钥库 | `/vault` | 主密码加密保存账号密码与各类 Key |
| 工具 | Git 报告 | `/daily-report` | 采集 Git 提交并用 AI 生成日报/周报 |

**页面内的维护入口**（不占侧边栏）：

- **工作区下拉**：技能库页顶部，覆盖 全局根目录 / 项目 / Agent 三类，按计数降序排列，计数为 0 的折叠进「更多」；沿用 `?root=` / `?project=` / `?agent=` 查询参数。侧边栏不再有动态列表。
- **来源目录**（`/skills/roots`）：技能库右上角按钮，登记全局根目录与项目目录。
- **回收站**（`/skills/trash`）：技能库右上角按钮，恢复/永久删除被删除的 Skill。
- **有问题**：技能库的筛选 Tab（原「问题中心」入口），旧路由 `/skills/issues` 会重定向到 `/skills/library?filter=issues`。

**侧边栏附加区域**

- **底部 footer（固定）**：设置（`/settings`）、主题切换（仅图标，点击循环 亮 / 暗 / 自动）、关于（版本号、支持的工具与登录命令）。侧边栏拆成头部（品牌）/ 导航区（独立滚动）/ footer 三段，任意路由下高度一致。

**页面渲染方式**：`用量` 三页（dashboard / analytics / subscriptions）与 `设置` 仍由 `src/views/DashboardView.vue` 按 `route.name` 渲染；`工具` 四页与 `MCP`、`Skills` 各页均为独立组件，工具页由 `src/layouts/WorkspacePage.vue` 补齐面板骨架。导航配置集中在 `src/config/navigation.ts`，新增入口只改配置。

## 2. 用量分组

### 2.1 概览（`/dashboard`）

**用途**：一屏掌握「花了多少钱、用了多少量、额度还剩多少」。

- **关键指标（驾驶舱）**：订阅月支出（计划）、本月实际支出（已记）、所选周期 Token 总量（含环比）、峰值利用率（全平台利用率最高的额度窗口，按 80%/100% 变色）。
- **概览卡片**：
  - 油价卡片（`OilPriceCard`）：展示配置省份/标号的今日指导价与调价预测，可跳设置页配置。
  - 今日工作卡片（`TodayWorkCard`）：今日 Git 提交概览，点击进入 Git 报告。
  - 套餐额度摘要（`QuotaSummary`）：各平台额度一览，点击进入订阅与账单。
- **顶部操作**：显示「N 个平台已连接」、上次同步相对时间、「同步全部」按钮（同时同步用量与油价）。
- **状态提示**：同步出错 / 部分数据未更新 / 首次无数据时显示可点击重试的 `UAlert`。
- 应用**不含任何种子/默认数据**，首次启动为空，需点「同步」拉取真实数据。

### 2.2 分析（`/analytics`）

**用途**：Token 用量的统计分析与可视化。

- **周期切换**：今天 / 7 天 / 30 天 / 90 天。
- **Token 概要（5 张卡）**：总 Token、输入 Token、输出 Token、请求数、预估费用（按模型单价估算），均带环比与迷你趋势线。
- **活跃热力图**：近一年每日 Token 分布（`CalendarHeatmap`）。
- **趋势图**：Token 趋势（`TokenTrendChart`）与各平台每日用量（`PlatformDailyChart`）；「今天」周期改为按小时时间轴。
- **工具维度**：工具用量列表（`ToolBreakdown`）+ 工具占比环形图（`ToolDonutChart`）。
- **模型维度**：模型用量明细（`ModelBreakdown`）。
- 图表在窗口激活后加载，桌面端首次进入可能短暂显示「图表将在窗口激活后加载」。

### 2.3 订阅与账单（`/subscriptions`）

**用途**：管理订阅计划，并记录真实账单流水。

- **套餐额度**：按平台/套餐展示可用额度、已用百分比与重置时间（`QuotaCard`），与「设置 → 显示设置」的额度显示开关联动。
- **订阅列表**：
  - 顶部工具条：USD 汇率（`1 USD = ¥`，默认 7.2）、「新增订阅」。
  - 列：服务 / 账号 / 金额 / 周期 / 下次续费 / 状态 / 操作。
  - 状态：生效中、即将续费（≤7 天）、已逾期、已暂停；行操作支持编辑、暂停/恢复、删除。
  - 订阅表单字段：服务商（含自定义）、套餐名称、账号、价格、币种（CNY/USD）、周期（月/年）、下次扣费日期、账单分类、支付方式、备注。
- **账单流水**：
  - 工具条：月份选择、分类筛选、「手动记账」。
  - 列：日期 / 服务 / 分类 / 支付方式 / 来源 / 金额（USD 附带折算 CNY）/ 操作。
  - 页脚显示当月合计；来源分为「手动记账」与「用量结算」。
- **摘要卡**：计划月支出、本月实际已记、7 天内续费数量。
- **关键设计**：计划支出（订阅折算）与实际支出（账单流水）是两个独立口径；**删除订阅不会删除历史账单**；系统不会自动根据续费生成账单。

## 3. Skills 分组

> Skills 页面全部依赖 Tauri 后端（Rust）与本机文件系统，仅桌面端可用。

### 3.1 概览（`/skills`）

**用途**：Skills 的总体视图与快捷入口。

- 统计卡：技能总数、校验通过数、来源目录（可写）数。
- 快捷按钮：「扫描本地 Skills」、「浏览技能库」。
- **近期动态**：按修改时间列出最近 6 个 Skill，点击进入详情。

### 3.2 技能库（`/skills/library`）

**用途**：浏览、筛选、新建与管理已安装的 Skill。

- **筛选**：搜索（名称/描述）、工作区下拉（全局 / 项目 / Agent，按计数降序，0 项折叠进「更多」）、范围（全部/全局/项目）、「全部 / 有问题」Tab（原问题中心）。从旧链接进入时按 `?root=` / `?project=` / `?agent=` / `?filter=issues` 过滤。
- **页头操作**：重新扫描、**来源目录**、**回收站**、新建 Skill。
- **列表**：按「名称 + 内容哈希」合并同名同内容 Skill，卡片显示版本、引用处数、软链接标记、涉及 Agent 头像，以及 错误 / 告警 标签（错误计入侧边栏徽章，告警只做行内提示）；点击进入详情。
- **「有问题」Tab**：额外列出无法解析的扫描失败目录（名称、所属来源目录、失败原因）。
- **新建 Skill**：「新建 Skill」弹窗（名称、描述、安装到根目录），在可写根目录下创建带 `SKILL.md` 的空白 Skill。
- 空态区分「没有匹配的技能」与「还没有任何技能」。

### 3.3 安装（`/skills/install`）

**用途**：从远程、本地路径或压缩包安装 Skill，走「预览 → 计划 → 确认安装」流程。

- **三个来源 Tab**：远程安装 / 本地路径 / 上传压缩包。
- **公共安装设置**：安装范围（全局 / 项目级）、项目选择、目标目录（可多选，未创建的 Agent 目录会折叠在「更多 Agent」下并自动创建）、同名冲突策略（保留两者 / 覆盖 / 跳过）。
- **远程安装**：来源类型（GitHub / skills.sh / 技能市场 / 任意 URL）；内置「技能目录」卡片，支持筛选、详情预览、一键安装；skills.sh 全网搜索（输入 ≥2 字符自动检索）；「数据源管理」可接入公开 GitHub 仓库作为目录源。
- **安装向导**：
  1. 候选选择（显示 `含脚本`/`二进制` 徽章与逐条问题，可安装项默认全选）；
  2. 计划确认（逐 Skill 逐目标显示 安装/覆盖/跳过/保留两者，风险提示需勾选确认）；
  3. 安装结果（逐目标显示 已安装/已跳过/失败，失败可重新生成计划重试）。
- **安全与事务**：SSRF 防护（拒绝本地/私网地址）、下载与解压限额（防压缩炸弹、Zip Slip）、staging 30 分钟过期、安装计划 15 分钟过期、确认指纹校验、原子事务安装（失败回滚、旧版本备份）。

### 3.4 来源目录（`/skills/roots`）

**用途**：登记 Skill 的全局根目录与项目目录，作为扫描与安装的目标位置。

- **全局根目录**：输入绝对路径添加；列表显示 Agent 头像、默认/只读/不存在标记、路径与 Skill 数；可重命名展示名、创建目录（不存在且可写时）、移除登记（不删文件）。
- **项目**：手动输入或「浏览」选择项目目录并可选展示名；「扫描目录发现项目」可递归扫描某目录，找出所有含 agent skill 的项目并「登记为项目」或「全部登记」；项目卡片显示探测到的各 Agent skill 根目录与数量。
- 所有「移除/删除」操作**只解除登记，不删除磁盘文件**。

### 3.5 回收站（`/skills/trash`）

**用途**：恢复或永久删除被删除的 Skill。

- 列表显示名称、根目录、原路径、删除时间、大小、是否为软链接。
- 操作：**恢复**（还原到原位置）、**永久删除**。
- 删除 Skill 会先移入回收站，可随时恢复。

> 原「问题中心」（`/skills/issues`）已收拢为技能库的「有问题」Tab；旧路由会自动重定向到 `/skills/library?filter=issues`，不再 404。

## 4. 工具分组

### 4.1 Git 报告（`/daily-report`）

**用途**：从本机多个 Git 仓库采集提交，调用 AI 生成可编辑的日报/周报。

- **报告类型**：日报 / 周报。
- **时间范围**：今天 / 昨天 / 本周 / 上周 / 自定义（起止日期）。
- **项目**：多选 Git 仓库（绝对路径，可「选择文件夹」添加、可移除），支持从 GitReport 配置导入；显示当前分支。
- **作者**：按作者过滤提交。
- **操作**：「仅读取 Git 记录」、「生成日报 / 生成周报」。
- **工作区 Tab**：报告预览（可编辑文本 + 复制）、Git 记录（提交 hash/信息/项目分支/日期）。
- **依赖**：本机 `git` 采集提交；AI Provider 支持 MiniMax / Kimi / DeepSeek（在「设置 → 高级 → AI 报告」配置 API Key）。
- **注意**：需填写 AI Provider 的 API Key 才能生成；所选范围内无提交会报错；API Key 以明文存于本机 localStorage。

### 4.2 代码片段（`/snippets`）

**用途**：保存、检索、复用代码、命令、Prompt、文本与链接片段，一键复制到系统剪贴板。

- **搜索**：标题/内容/标签（FTS5 全文检索，`⌘K` 聚焦）。
- **筛选**：范围（全部 / 最近 / 置顶）、类型（代码 / 命令 / Prompt / 文本 / 链接）、排序（最近使用 / 最近更新 / 创建时间 / 标题 / 使用次数）、标签栏。
- **新建**（`⇧⌘N`）/ 编辑 / 预览 / 删除（永久删除，无回收站）。
- 卡片操作：复制、置顶/取消置顶、查看完整内容、编辑、删除；显示使用次数与更新时间。
- **存储**：本机 SQLite（表 `snippets`/`tags`/`snippet_tags`/`snippets_fts`）；复制会累计使用次数与最近使用时间。

### 4.3 剪贴板历史（`/clipboard`）

**用途**：浏览、检索并复用本机自动采集的剪贴板历史（文本 / 图片 / 文件）。

- **采集控制**：显示「正在记录 / 已暂停」，可暂停/继续。
- **搜索**：内容或来源应用。
- **类型导航**：全部 / 文本 / 图片 / 文件 / 已收藏。
- **列表**：按 已收藏 / 今天 / 昨天 / 过去 7 天 / 更早 分组；显示来源应用、时间、使用次数、置顶标记。
- **交互**：单击选中、双击/回车复制、`↑↓` 切换、空格预览、`Shift+Enter` 纯文本复制、`Delete` 删除。
- **预览面板**：文本自动语言高亮、图片全图、文件（文本/图片/PDF）预览；操作：复制、纯文本、保存为片段、删除。
- **清空历史**：可勾选「同时删除收藏记录」。
- **全局快捷面板**：默认 `⌘⇧V` 唤起独立剪贴板面板。
- **权限**：macOS 需辅助功能权限（用于来源应用识别与自动粘贴），未授权时顶部横幅提示。
- **隐私与限额**：带 `concealed`/`transient` 语义（密码管理器）的内容不采集；可配置「不记录这些应用」（默认含常见密码管理器）；文本 >200KB 不采集；按 SHA-256 去重；非收藏记录按保留天数（默认 3 天）与容量上限（默认 100 条）自动清理，收藏记录不参与清理。

### 4.4 密钥库（`/vault`）

**用途**：以主密码加密保存账号密码、AI Key 与其他 Key。

- **初始化/解锁**：首次设置主密码（≥8 字符），之后用主密码解锁；主密码不保存，遗忘无法恢复。
- **记录类型**：全部 / 账号密码 / AI Key / 其他 Key（含各类计数）。
- **筛选**：搜索（名称或账号）、排序（最近使用 / 名称 / 创建时间）、标签栏。
- **记录表格**：名称（含收藏）、类型与标签、账号/服务商（可打开登录地址，仅 http/https）、密码/Key（显示 15 秒后自动隐藏；复制 30 秒后尝试清空剪贴板）、编辑、删除。
- **记录表单**：按类型切换（账号密码 / AI Key / 其他 Key），含名称、账号、密码/Key、登录地址/Base URL、标签、备注、收藏置顶。
- **密钥库设置**：自动锁定（1/5/15/30/60 分钟，默认 15 分钟，闲置后清除内存密钥）、修改主密码（重新加密全部记录）、导出加密 JSON 备份、导入备份（需备份文件的主密码，会覆盖当前记录）、立即锁定。
- **加密**：AES-256-GCM + PBKDF2-SHA256（迭代 310000）；数据文件 `xlt-vault.enc.json` 权限 `0600`，仅存本机。

## 5. MCP 分组（预留）

### 5.1 MCP 服务（`/mcp`、`/mcp/new`）

**用途**：管理各 Agent 的 MCP 服务配置（列表 + 启停 + 编辑）。当前为**只读占位**，检测与写入能力待接入。

- 与 Skills 共用同一个「工作区」筛选组件（全局 / 项目 / Agent）。
- 「添加 MCP」为页内按钮，`/mcp/new` 会直接打开添加抽屉。
- 配置异常（解析失败、命令不存在）计划以**行内状态标签**展示，不另开问题中心。
- 写入策略（接入时生效）：先只读检测，再写入；写入前备份并保留未知字段；环境变量与 Token 支持引用密钥库，避免明文落盘。

## 6. 设置（footer）

### 6.1 设置（`/settings`）

**用途**：集中管理外观、统计口径、连接器状态、剪贴板与 AI 报告配置。分 4 个 Tab。

- **通用**
  - 外观主题（亮 / 暗 / 自动）。
  - 统计时区（日/小时分桶所用 IANA 时区，默认跟随系统）。
  - 统计起始日（早于该日期的数据不纳入分析与同步）。
  - 油价监控：油品标号（92#/95#/98#/0#）、监控省份、可选预测 API Key。
  - 套餐额度展示：勾选是否在额度区域显示 Codex / 火山方舟 Coding / 火山方舟 Agent / Kiro / Qoder / Kimi（仅隐藏显示，不删数据）。
- **平台连接**
  - 火山方舟登录状态检测（`arkcli auth login volc-sso`）。
  - 本机 CLI 连接器清单（只读）：Codex、Claude Code、OpenCode、Kiro CLI、Qoder、Kimi、Gemini CLI、GitHub Copilot。
- **剪贴板**（仅桌面端）：辅助功能权限、自动记录开关、登录时自动启动、容量上限、保留时长、全局快捷键、不记录的应用名单、本机存储位置。
- **高级**
  - AI 报告：Provider（MiniMax / Kimi / DeepSeek）、模型、API Key（仅本机保存）。
  - 数据与存储：显示存储引擎（桌面端 SQLite / 浏览器 localStorage）。
- **底部操作**：「保存」（仅保存）、「立即同步」（保存并触发全量同步）。

## 7. 用量同步机制（跨页面）

- **首次同步**：应用不含种子数据；桌面端启动时只拉取额度（避免扫描完整 Token 历史），浏览器端全量同步。
- **自动刷新「今天」**：每 60 秒 + 窗口重新可见/获得焦点时静默重拉本地会话类 Token（排除 Ark，避免网络调用），仅覆盖「今天」。
- **全量同步**：并发执行额度连接器（ark / codex / kiro / qoder / kimi）与 Token 连接器（ark / codex / opencode / claude / kiro / qoder / gemini / copilot / kimi）；单连接器超时 25 秒，失败不阻塞其他平台。
- **结果状态**：`success` / `partial` / `failed`，分别对应 Toast 与概览页提示；部分失败可点击重试。
- **各连接器数据来源**：
  - 火山方舟：本机 `arkcli`（Volc SSO 签名，需 `arkcli auth login volc-sso`）。
  - Codex：`~/.codex/sessions` 逐请求 Token + 官方 5h/weekly 额度。
  - Kiro：`kiro-cli` Credits + 本地会话 Token（估算）。
  - Qoder：官方 SDK Credits + 本地 SQLite Token（真实计数）。
  - Kimi：OAuth 会员额度 + `~/.kimi-code/sessions` 真实 Token。
  - OpenCode：本机 OpenCode 数据库逐请求 Token。
  - Claude Code / Gemini CLI / GitHub Copilot：读取各自本机会话文件。
- **存储**：用量数据存本机 localStorage（`xlt.quotas` / `xlt.tokens` / `xlt.sync` 等）；Skills / 片段 / 剪贴板存本机 SQLite；密钥库为加密文件。

## 8. 仅桌面端可用能力

以下入口/页面依赖 Tauri 原生能力，浏览器模式下不可用：
