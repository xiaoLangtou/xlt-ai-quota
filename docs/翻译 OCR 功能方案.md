# 翻译 / OCR 功能方案

xlt-workbench · 工具 / 翻译 · v1.0 · 2026-10-27

> 参考对象：Manggo（桌面翻译与截图 OCR 助手）、Pot。Manggo 官网 #features 为前端渲染，未能读取功能明细；本方案按其定位描述（学术文献阅读、跨语言快捷交流，覆盖笔记、选区、屏幕与声音）和 Pot 的公开功能做参照，落地前需与官网逐项核对。

## 1. 背景与目标

- 工作台已有用量、Skills、工具、系统四组功能，缺少日常阅读英文文档与文献时的翻译能力。
- 目标：提供划词、输入、截图、剪贴板统一的翻译入口，译文可追溯、可对比、术语一致，数据留在本机。
- 与 Manggo 的差异：不按输入方式分页，所有翻译进入同一条翻译流；译文逐句对齐；快捷面板结果优先；术语表贯穿全文。

## 2. 范围

| 范围内 | 非目标（v1 不做） |
| --- | --- |
| 文本翻译、划词翻译、截图识别与截图翻译、剪贴板监听、快捷面板、翻译流（含收藏与历史）、术语表、设置 | 整篇 PDF 或网页翻译、语音输入翻译、云同步、插件市场 |

## 3. 目标场景

1. 读英文文档时划词，在鼠标旁弹出快捷面板，看译文，可替换选区。
2. 看到图片或视频里的文字，截图后识别并翻译。
3. 写作或查词时，用快捷面板输入翻译，再展开到工作区细看。
4. 阅读论文段落时对比多个引擎，并用术语表保证全文译法一致。
5. 回头查找翻译过的内容，收藏常用词句。

## 6. 交互设计

### 6.1 入口与快捷键

| 动作 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 唤起快捷面板 | Alt+Space | 空白面板，焦点在输入框 |
| 划词翻译 | Alt+D | 取选中文字，面板内自动翻译 |
| 输入翻译 | Alt+A | 打开面板并聚焦输入框 |
| 截图识别 | Alt+S | 框选后识别 |
| 截图翻译 | Alt+Shift+S | 框选后识别并翻译 |
| 显示主窗口 | Alt+W | 回到工作区 |
| 开关剪贴板监听 | Alt+C | 开启后复制即翻译 |

规则：全局快捷键必须包含修饰键；与其他动作冲突时提示并拒绝；可一键恢复默认。

### 6.2 翻译流

- 按时间倒序；新记录自动选中。
- 每条显示：来源（色点加文字）、时间、收藏标记、首句原文（最多两行）、首个引擎的译文（一行）。
- 过滤标签显示数量；搜索同时匹配原文和译文。
- 无匹配时显示空状态。

### 6.3 工作区

- 逐句对照：左原文、右译文（译文用衬线体，便于长文阅读）。
- 顶部工具栏：语言方向、引擎分段控件、对比引擎、术语高亮、术语表。
- 悬停某句出现「换引擎重译」和「复制译文」；被单独指定引擎的句子标注引擎名。
- 截图记录在顶部多一栏：识别区域大小、OCR 引擎、置信度、重新识别。
- 底部操作栏：复制译文、复制双语、朗读、存为片段。

### 6.4 快捷面板

- 结构：顶栏（模式标签、固定、关闭）、输入框（语言方向按钮、翻译按钮）、译文卡、操作栏。
- 译文卡为视觉焦点：引擎名与耗时、译文、命中的术语标签、引擎切换。
- 触发：停顿 0.7 秒自动翻译（可配置），Enter 立即翻译，Esc 关闭。
- 划词模式：预填选中文字并自动翻译，额外提供「替换选区」。
- 截图模式：显示识别区域大小，预填识别文字。
- 操作：复制译文、收藏、展开到工作区。
- 状态：空闲、翻译中、完成、失败（显示原因与重试）。

### 6.5 截图流程

1. 按截图快捷键，出现全屏遮罩，框选区域。
2. 取图并裁剪，调用默认 OCR 引擎。
3. 若开启「识别后自动翻译」，继续翻译。
4. 结果入流，并在快捷面板展示；可展开到工作区。
5. 需处理多显示器与 HiDPI。

### 6.6 设置页

| 分类 | 内容 |
| --- | --- |
| 翻译服务 | 有道（应用 ID、应用密钥）；DeepL（接口类型、API Key）；LLM 翻译，OpenAI 兼容（Base URL、模型、API Key、提示词）；Ollama（服务地址、模型）；百度翻译（APP ID、密钥）；可添加自定义 OpenAI 兼容服务。每项支持启用、默认、上移下移、测试连接。 |
| 识别服务 | 系统 OCR（识别语言）；Tesseract.js（语言包）；PaddleOCR（模型目录）；百度 OCR（API Key、Secret Key）。另有：识别后自动翻译、保留原文换行、自动复制识别文字。 |
| 快捷键 | 见 6.1，点击按键框后直接按新组合录制。 |
| 常规 | 外观与语言（主题、默认源与目标语言）；翻译（学术模式、术语高亮默认值）；快捷面板（自动翻译及延迟、失焦隐藏、跟随鼠标、记住位置、打开时读取剪贴板）；系统（开机自启、关闭到托盘、网络代理）；历史与数据（保留时长、导出、清空）。 |

所有 API Key 字段从「密钥库」选择，不在设置页明文保存。

### 6.7 异常与空状态

- 引擎失败：显示原因并提供重试，不影响其他引擎。
- 无网络：提示切换到本地引擎。
- OCR 未识别到文字：提示重新框选。
- 未配置任何引擎：引导前往设置。
- 快捷键冲突或系统占用：提示并保留原设置。

## 7. 数据模型

```ts
type Source = 'input' | 'select' | 'shot' | 'clip'

interface Capture {
  id: string
  source: Source
  app?: string                 // 来源应用
  createdAt: number
  starred: boolean
  from: string
  to: string
  sentences: Sentence[]
  ocr?: { engine: string; width: number; height: number; confidence: number }
}

interface Sentence {
  original: string
  translations: Record<string, string>   // engineId -> 译文
  picked?: string                         // 单句指定的引擎
}

interface Term { src: string; dst: string; note?: string }
```

SQLite 表（Tauri 就绪后迁移，沿用现有 Storage 接口，先用 localStorage）：

| 表 | 主要字段 |
| --- | --- |
| capture | id, source, app, created\_at, starred, from\_lang, to\_lang, ocr\_json |
| sentence | id, capture\_id, idx, original, picked\_engine |
| translation | sentence\_id, engine\_id, text, ms |
| term | id, src, dst, note |
| setting | key, value\_json |

## 8. 技术方案

### 8.1 架构

- Rust 侧（Tauri）：全局快捷键、取词、截图、系统 OCR、窗口管理、托盘、读取密钥库。
- 前端侧：页面与状态、拆句与对齐、术语表处理、引擎适配的调用编排。
- 云端请求经 Rust 侧发出，避免跨域，也避免密钥进入前端。

### 8.2 关键点

| 项 | 方案 | 注意 |
| --- | --- | --- |
| 划词取词 | 优先读系统选中文本接口；回退为模拟复制、读剪贴板、还原剪贴板 | macOS 需辅助功能权限；Linux Wayland 受限 |
| 截图 | 取各显示器画面，透明全屏窗口框选，裁剪后送 OCR | macOS 需屏幕录制权限；多屏与 HiDPI |
| 系统 OCR | macOS 用 Vision，Windows 用系统 OCR，Linux 用 Tesseract | 各平台语言包差异 |
| 快捷面板窗口 | 无边框、置顶、不入任务栏；失焦隐藏（可固定）；出现在鼠标附近并防止出屏 | 全屏应用下的显示行为需实测 |
| 密钥 | 设置页只保存密钥库引用，请求时由 Rust 侧读取 | 日志不记录密钥与原文 |
| 拆句 | 按句末标点切分，英文维护缩写白名单（e.g.、Fig.、et al.）；中文按。！？；失败回退整段 | 句数对不上时回退整段并标记 |
| 朗读 | 系统 TTS | 离线可用 |

### 8.3 引擎接口

```ts
interface TranslateEngine {
  id: string
  name: string
  kind: 'cloud' | 'local'
  translate(req: { sentences: string[]; from: string; to: string; glossary: Term[] }): Promise<string[]>
  test(): Promise<{ ok: boolean; ms: number; error?: string }>
}

interface OcrEngine {
  id: string
  name: string
  kind: 'cloud' | 'local'
  recognize(img: Uint8Array, opts: { lang: string; keepLineBreaks: boolean }): Promise<{ text: string; confidence: number }>
}
```

新增引擎只需实现接口并在设置页注册，翻译流与工作区不感知具体引擎。

### 8.4 翻译请求流程

1. 拆句。
2. 注入术语表（LLM 引擎写入提示词；其他引擎翻译后做术语校对高亮）。
3. 并行请求所有已启用引擎。
4. 对齐校验：返回句数与原文不一致时，该引擎回退为整段结果并标记。
5. 写入记录，渲染翻译流与工作区。

## 9. 与工作台的集成

- 侧边栏：「工具」分组新增「翻译」。
- 密钥库：翻译与识别引擎的密钥统一引用。
- 剪贴板历史与片段库：译文可存为片段；剪贴板监听复用剪贴板模块，避免重复监听。
- 用量分析：LLM 翻译的 token 是否计入用量看板，待确认（P2）。
- 设置：快捷键与全局选项使用独立命名空间，避免与现有设置冲突。

## 10. 隐私与安全

- 本地优先：翻译记录只存本机。
- 云端翻译只发送待翻译文本；截图图片默认不上传，仅在用户启用云端 OCR 时上传。
- 「仅本地引擎」模式下禁用所有云端服务。
- 密钥不明文保存；日志不记录原文与密钥。
- 支持历史保留时长与一键清空。
- 后续可对敏感窗口（如密码管理器）禁用取词与入流。

## 12. 验收与测试要点

- 功能：每个 P0 功能按 6 章规则逐条验证。
- 兼容：macOS（含 Apple Silicon）、Windows；Linux 按能力降级。
- 权限：未授予辅助功能或屏幕录制权限时，有明确引导而非静默失败。
- 性能：快捷键唤起到面板可输入应在可感知的瞬时范围内；翻译中不阻塞输入。
- 容错：断网、引擎超时、返回句数不一致、OCR 空结果。
- 数据：历史保留与清空、导出、迁移后的一致性。

## 13. 风险与待确认

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 划词取词在各系统行为不一 | 部分应用取不到文字 | 双通道取词，失败时提示并允许手动粘贴 |
| 系统权限缺失 | 取词或截图失败 | 首次使用引导授权，设置页提供检测 |
| 全局快捷键被占用 | 无法唤起 | 录制时检测，提供备选默认值 |
| 云端引擎限流或收费 | 翻译失败或成本 | 并行但可选；本地引擎兜底 |
| 拆句不准 | 对照错位 | 缩写白名单、可回退整段 |

待确认问题：

1. 首批翻译引擎是否以有道、DeepL、LLM 为主，是否需要百度、腾讯、Bing。
2. Linux Wayland 的支持范围。
3. LLM 翻译的 token 是否并入用量看板。
4. 是否需要独立的生词本页面（当前合并为翻译流中的收藏）。
5. 与 Manggo 官网功能点逐项核对，补齐遗漏。
