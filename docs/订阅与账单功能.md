# 订阅管理与账单流水 · 功能文档

面向 AI 用量看板（xlt-workbench）中「订阅与账单」模块的功能说明。该模块本地优先，所有数据仅保存在本机浏览器 `localStorage`，不上传、不依赖第三方 API。

---

## 1. 概览

「订阅与账单」是侧边栏的一个工作区，内含两个标签页：

| 标签 | 职责 |
| --- | --- |
| **订阅** | 管理各 AI 服务的订阅计划（服务商、套餐、账号、价格、周期、续费日、分类、支付方式）。 |
| **账单流水** | 账单台账：记录每一笔**真实发生**的花费（手动记账 / 用量结算），可按月份 / 分类筛选。 |

### 设计原则：计划与实际相互独立

本模块把两个指标彻底分开，不再假装它们是同一份数据：

- **订阅月支出（计划口径）**：由订阅表实时计算，代表「按订阅计划每月应付多少」。
- **本月实际支出（账单口径）**：由账单流水里的真实记录汇总，代表「这个月实际记了多少」。

两者**允许不一致**，且这种不一致是有用的对账信号。例如订阅计划 ¥500/月，但本月只手动记了 ¥300，说明还有一笔账没记。系统**不会自动生成账单**去凑平这两个数字。

### 信息架构（页面位置）

| 页面 | 承载内容 |
| --- | --- |
| **用量概览** | 摘要驾驶舱条（7 天 Token / 订阅月支出·计划 / 本月实际支出·已记 / 峰值利用率）+ 订阅额度**汇总卡**（每平台一行 mini 进度条，异常标红，右上角「前往订阅与账单」）。首屏可见，无需滚动。 |
| **用量分析** | Token 使用量明细（今天/7天/30天切换）+ 使用趋势图 + 平台分布图。 |
| **订阅与账单** | 页首屏为**平台额度完整详情**（4 张额度卡），其下为「订阅 / 账单流水」两个标签页。 |
| **连接与设置** | 各本机连接器状态与说明。 |

## 2. 核心概念与数据模型

### 2.1 订阅 `AiSubscription`

| 字段 | 说明 |
| --- | --- |
| `provider` | 服务商名称（如 ChatGPT、Claude、Cursor，或自定义） |
| `planName` | 套餐名称（Plus / Pro / Team 等） |
| `account` | 账号（邮箱或备注） |
| `price` / `currency` | 价格与币种（`CNY` / `USD`） |
| `billingCycle` | 计费周期：`monthly`（月付）/ `yearly`（年付） |
| `nextBillingDate` | 下次扣费日期（`YYYY-MM-DD`） |
| `status` | `active`（生效中）/ `paused`（已暂停） |
| `category` | 账单分类，供手动记账关联时带出 |
| `paymentMethod` | 默认支付方式，供手动记账关联时带出 |
| `note` | 备注 |

### 2.2 账单 `BillEntry`

一条真实发生的花费记录（手动记账 / 用量结算）：

| 字段 | 说明 |
| --- | --- |
| `date` | 记账/扣费日期（`YYYY-MM-DD`） |
| `subscriptionId` | 关联订阅（可选，仅用于记账时带出金额/分类，方便填表） |
| `service` | 服务名称（关联订阅名或手动填写） |
| `category` | 分类 |
| `amount` / `currency` | 金额与币种 |
| `paymentMethod` | 支付方式 |
| `source` | 来源：`usage_settlement`（用量结算）/ `manual`（手动记账） |
| `note` | 备注 |

> 每条账单都**自带服务名、金额、分类等快照**，不依赖订阅记录。因此订阅被删除后，账单依然完整可读、不受影响。

### 2.3 枚举与标签

- **分类 `BillCategory`**：模型订阅 / 编程工具 / API 中转 / 图像·多媒体 / 其他
- **支付方式 `BillPaymentMethod`**：支付宝 / 微信 / 信用卡 / PayPal / 余额 / 其他
- **来源 `BillSource`**：用量结算 / 手动记账

## 3. 订阅管理功能

### 3.1 列表
表格列：服务（图标 + 服务商 + 套餐）、账号、金额、周期、下次续费、状态、操作。

- **账号**过长时省略号显示，鼠标悬停可看完整内容（`title` 提示）。
- **状态**根据下次续费日自动派生并用不同颜色标记：
  - 生效中（正常）
  - 即将续费（距今 ≤ 7 天，琥珀色）
  - 已逾期（已过续费日，红色）
  - 已暂停（灰色）

### 3.2 新增 / 编辑
右上「新增订阅」打开表单，字段包含：服务商（含自定义）、套餐、账号、价格、币种、计费周期、下次扣费日期、账单分类、支付方式、备注。

### 3.3 行操作
每行主操作为「编辑」，其余收进「···」菜单：
- **暂停 / 恢复**：暂停后不计入订阅月支出。
- **删除**：仅删除订阅本身，**历史账单保留**（见 [5.2](#52-删除订阅不影响历史账单)）。

### 3.4 USD 汇率
订阅页工具栏可设置「1 USD = ¥ 汇率」。USD 计价的订阅与账单在做人民币合计时按此汇率折算。汇率保存在本机偏好设置中，默认 `7.2`。

## 4. 账单流水功能

### 4.1 台账表格
表格列：日期、服务（图标 + 服务名 + 备注）、分类（标签）、支付方式、来源、金额、操作。

- 表尾显示「当前月份合计」；当月会标注「（截至今日）」。此合计只统计**真实记录**，语义即「这个月实际花了多少」。
- 金额为 USD 时同时显示「≈ ¥折算值」。
- 行操作：主操作「编辑」，「···」菜单内提供「删除」。

### 4.2 筛选
- **月份选择器**：查看指定月份的账单。
- **分类下拉**：全部分类 / 按某一分类过滤。

合计随当前筛选条件实时计算。

### 4.3 手动记账
右上「＋ 手动记账」打开表单：日期、关联订阅（可选，选后自动带出服务/分类/支付方式/币种/金额，仅为方便填表）、服务、分类、金额、币种、支付方式、来源、备注。

- 「关联订阅」可选「不关联（手动记账）」。
- 来源可选：**手动记账 / 用量结算**（系统不再自动生成账单）。

---

## 5. 关键行为说明

### 5.1 不做自动生成
账单流水是纯粹的记录台账，只有用户主动「手动记账」或记录「用量结算」才会产生。系统**不会**根据订阅到期自动写入账单，因此不存在任何「自动生成 / 去重 / 删了又冒出来」的状态机。

### 5.2 删除订阅不影响历史账单
删除订阅**只移除订阅计划本身**，账单流水中已产生的记录全部保留（它们是已经发生的花费，属于财务历史）。

### 5.3 计划支出的计算
`computeMonthlySubscriptionSpend(subscriptions, usdToCnyRate)`：取所有**生效中**订阅，年付 ÷ 12、USD 按汇率折算为 CNY，累加得到订阅月支出。概览页「订阅月支出 · 计划」直接来自此函数，**不读账单表**。

---

## 6. 概览页两个支出指标

概览驾驶舱条同时展示：

| 指标 | 口径 | 数据来源 |
| --- | --- | --- |
| **订阅月支出 · 计划** | 计划应付 | 订阅表实时计算（`computeMonthlySubscriptionSpend`） |
| **本月实际支出 · 已记** | 实际已记 | 账单流水中当月真实记录合计 |

两个数字相互独立，差额即「尚未记账 / 计划外」的信号。

---

## 7. 货币折算

- 合计统一折算为人民币展示。
- 规则：`CNY` 原样计入；`USD` 金额 × `usdToCnyRate`。
- 汇率在订阅页工具栏设置，默认 `7.2`。

---

## 8. 数据存储

全部保存在本机 `localStorage`：

| Key | 内容 |
| --- | --- |
| `xlt.subscriptions` | 订阅列表 |
| `xlt.bills` | 账单台账（真实记录） |
| `xlt.subscription-preferences` | 偏好设置（USD 汇率） |

### 一次性数据迁移
应用加载时（`web-storage.ts` 的 `migrateLegacyBills`）会执行一次性迁移：
- 旧版「订阅自动生成」的账单 `source = auto_renew` 静默改为 `usage_settlement`（语义最接近：系统曾推断的一笔结算），历史记录**保留不删除**。
- 清理已废弃的去重键 `xlt.bill-auto-keys`。

> 待 Tauri 桌面壳就绪后，`UsageStorage` 抽象可切换为 SQLite 实现，接口不变。
